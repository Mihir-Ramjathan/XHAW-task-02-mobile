## WIL Task 2 – Phase 2

This repository contains the **mobile application design and prototype** developed for Pawsitive Pet Academy as part of the Work Integrated Learning (WIL) project.

The mobile application is designed to provide users with an easy and convenient way to learn about Pawsitive Pet Academy, view its courses and services, make enquiries, and access contact information.

---

## About Pawsitive Pet Academy

Pawsitive Pet Academy is a Durban-based pet care education and practical animal training business.

The organisation provides pet-related training and educational courses to help pet owners improve their knowledge and skills when caring for their pets.

The mobile application forms part of a digital solution intended to improve the way customers access information and interact with the organisation.

---

## Project Purpose

The purpose of the mobile application is to create a simple and user-friendly platform where users can:

* Learn about Pawsitive Pet Academy.
* View available courses.
* View course information and pricing.
* Learn about the organisation.
* Make enquiries.
* Access contact information.
* Navigate easily between different sections of the application.

---

## Course Discount Structure

Pawsitive Pet Academy offers discounts based on the number of courses selected.

| Number of Courses |    Discount |
| ----------------- | ----------: |
| 1 Course          | No discount |
| 2 Courses         |          5% |
| 3 Courses         |         10% |
| 4 or more Courses |         15% |

This information is included in the mobile application design to help users understand the available course discounts.

## UI/UX Design

The mobile application was designed using user interface and user experience principles.

The design focuses on:

* Simple and clear navigation.
* Consistent colours and typography.
* Clear buttons and labels.
* Readable text.
* Consistent layouts.
* Appropriate images and visual elements.
* Easy access to important information.
* A clean and professional appearance.

High-fidelity wireframes were created in Figma to show the final appearance of the mobile application.
